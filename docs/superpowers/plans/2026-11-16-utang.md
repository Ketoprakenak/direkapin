# Utang (FIN-20) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Catat utang owner (ditalangin atau pinjam tunai), cicil sebagai pengeluaran berkategori, dan tampilkan sisa utang di menu gabungan Utang & Piutang serta sheet Saldo total.

**Architecture:** Reuse tabel FIN-19. `Receivable` dapat kolom `direction` (default `RECEIVABLE`) dan `loanTransactionId`. Cicilan `PAYABLE` = transaksi EXPENSE berkategori pilihan lewat `receivable_payments` yang sama; pinjam tunai = INCOME "Pinjaman diterima". Mobile: layar Piutang jadi `Utang & Piutang` dengan toggle arah.

**Tech Stack:** Fastify 5 + Zod + Prisma 6 (PostgreSQL 16), vitest; Flutter 3 (Riverpod generator, freezed, go_router).

**Spec:** `docs/superpowers/specs/2026-11-16-utang-design.md`

## Global Constraints

- Tanpa dependency baru.
- `schema.prisma`: hanya enum `ReceivableDirection { RECEIVABLE PAYABLE }`, `Receivable.direction @default(RECEIVABLE)`, `Receivable.loanTransactionId String? @unique @db.Uuid` (relasi `Transaction`, `onDelete: SetNull`), `Transaction.receivableLoan Receivable?`. Tidak ada index baru. Satu migrasi `<ts>_payables`, jalan di DB kosong dan di DB berisi piutang. Edit manual, jangan `prisma format`.
- Semua query difilter `userId`; milik user lain → 404 di URL, 400 di body (D-27).
- Nominal BigInt Rupiah 1..999.999.999, JSON integer.
- Kategori bawaan pinjaman: `{ name: 'Pinjaman diterima', type: 'INCOME', icon: 'handshake_rounded', color: '#64748B' }` via `upsert` `userId_name_type`.
- Catatan transaksi: pinjaman `Pinjam <nama> · <judul>`; cicilan utang `Bayar utang <nama> · <judul>`; cicilan piutang tetap `Bayar <nama> · <judul>`. Semua `.slice(0, 1000)`.
- Copy persis: `Utang & Piutang`, `Piutang`, `Utang`, `Total utang`, `Catat utang`, `Belum ada utang`, `Utang ke`, `Ditalangin`, `Pinjam tunai`, `Masuk ke dompet`, `Dari dompet`, `Kategori`, `Pinjaman masuk ke <dompet>`, `Utang hanya untuk 1 orang`, `Pilih kategori`.
- `totalBalance` dashboard **tidak berubah rumusnya** (D-76). `payableRemaining` hanya info.
- Mobile: `FrameCard`/`FrameBox`, warna tema, format lewat `core/format/`, `refreshMoney(ref)`. Sheet di atas shell pakai `useRootNavigator: true`. `FilledButton` di Row butuh `minimumSize`.
- Balikin churn line ending hasil build_runner. Tidak ada commit sampai owner minta.
