# Tabungan (FIN-18) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tabungan (dengan target nominal opsional) = "dompet tersembunyi" yang mengurangi Saldo bisa digunakan, bisa disetor berkali-kali, dipakai untuk pengeluaran, dan dihapus dengan sisa dikembalikan; rinciannya muncul di bottom sheet saat kartu Total saldo di Beranda di-tap.

**Architecture:** Enum `WalletType` ditambah `SAVINGS`; setor = `Transfer`, pengeluaran = `Transaction` biasa, jadi saldo/laporan/budget tidak butuh logika baru. Modul backend baru `savings` (buat + hapus) dan dashboard ditambah `availableBalance` + `savings`. `GET /wallets` menyembunyikan SAVINGS kecuali diminta, supaya APK lama tidak rusak.

**Tech Stack:** Fastify 5 + Zod + Prisma 6 (PostgreSQL 16), vitest; Flutter 3 (Riverpod generator, freezed, go_router).

**Spec:** `docs/superpowers/specs/2026-11-16-tabungan-design.md`

## Global Constraints

- Tanpa dependency baru.
- `schema.prisma`: `enum WalletType` + `SAVINGS`, `Wallet.targetAmount BigInt?`. Satu migrasi `<ts>_savings` (`ALTER TYPE "WalletType" ADD VALUE 'SAVINGS';` + `ALTER TABLE "wallets" ADD COLUMN "targetAmount" BIGINT;`), harus jalan di DB kosong.
- `openapi.yaml`: tambah `/savings`, `/savings/{id}`, query `includeSavings`, `SAVINGS` di enum, field dashboard `availableBalance` + `savings`.
- Semua query difilter `userId`; milik user lain → 404. ID asing di body → 400, di URL → 404 (D-27).
- Nominal BigInt Rupiah, JSON integer.
- Ikon tabungan selalu `savings_rounded`.
- Copy persis: `Tabungan tidak bisa ditarik`, `Pilih dompet untuk sisa saldo`, `Pilih dompet`, `Belum ada tabungan`, `Saldo total`, `Bisa digunakan`, `Tabungan`, `Buat tabungan`, `Setor`, `Catat pengeluaran`, `Ubah target`, `Hapus`, `Tanpa target`, `Tercapai`, `N% dari Rp…`, `Kurang Rp…`.
- Mobile: warna/ukuran dari tema & `Spacing`; format lewat `core/format/`; layar menangani loading/kosong/error; `refreshMoney(ref)` setelah data uang berubah; form pakai `SingleChildScrollView` + `Column`.
- Format hanya file yang disentuh (`dart format <file>`). Tidak ada commit sampai owner minta (pola Slice 12+).

## Review Focus

1. APK 1.3.0 memanggil `GET /wallets` dan `GET /dashboard` setelah user punya tabungan → tidak ada `type: "SAVINGS"` di respons → test Task 1 & 2.
2. Hapus tabungan dengan sisa negatif (pengeluaran > setoran) → transfer dompet → tabungan sebesar kekurangan, saldo dompet turun → test Task 2.
3. Hapus tabungan dua kali / tabungan user lain / id dompet biasa di `/savings/{id}` → 404 → test Task 2.
4. `PATCH /transfers/{id}` mengganti `fromWalletId` ke tabungan → 400 → test Task 1.
5. Edit transaksi lama yang dompetnya tabungan terhapus → form tetap menampilkan dompet itu (D-28) → test Task 5.
